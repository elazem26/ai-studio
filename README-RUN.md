# AI Clothing Studio — نسخة الكمبيوتر الكاملة

استوديو تبديل الملابس والوجوه بالذكاء الاصطناعي — يعمل محلياً 100% على جهازك.

## المتطلبات
1. **Bun** (مطلوب): https://bun.sh — `curl -fsSL https://bun.sh/install | bash`
2. **Python 3.10+** (لخدمة تبديل الوجه): https://python.org
3. **ffmpeg** (للفيديو)

## خطوات التشغيل (3 أوامر فقط)

```bash
# 1) تثبيت حزم المشروع
bun install

# 2) تجهيز قاعدة البيانات
bunx prisma db push && bunx prisma db generate

# 3) تشغيل كل الخدمات (الواجهة + خدمة تبديل الوجه)
bash start.sh
```

ثم افتح المتصفح على: **http://localhost:3000**

## محتويات الحزمة
| المجلد/الملف | الوصف |
|---|---|
| `src/` | كود التطبيق كاملاً (Next.js 16) |
| `db/custom.db` | قاعدة البيانات (المستخدمون والإعدادات) |
| `.env` | المفاتيح والإعدادات |
| `mini-services/face-swap-pro/` | خدمة تبديل الوجه (Python) + النماذج |
| `scripts/` | سكربتات النسخ الاحتياطي والاستعادة |
| `start.sh` | تشغيل كل الخدمات بأمر واحد |

## النماذج
الحزمة الكاملة تشمل نماذج تبديل الوجه:
- `mini-services/face-swap-pro/models/inswapper_128.onnx`
- إذا كان مجلد `home/z/.insightface/models/` موجوداً في الحزمة، انسخه إلى `~/.insightface/models/` في جهازك.

## النسخ الاحتياطي
- زر «إنهاء الجلسة» في التطبيق ينظف الصور/النتائج ثم يحفظ 6 نسخ
  (5 خارج المشروع + 1 داخله) ويجهّز نسخة GitHub نظيفة.
- لاستعادة النماذج من حزمة أخرى: `bash scripts/restore-models.sh /مسار/الحزمة`

## ملاحظة أمنية
ملف `.env` يحتوي مفاتيح API — لا تشارك هذه الحزمة مع أي أحد.
