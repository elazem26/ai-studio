الطريقة 1: التشغيل من الكمبيوتر (هذه النسخة)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. فك ضغط الملف في أي مجلد تريده
2. اضغط مرتين على الملف المناسب لنظامك:
      ويندوز : START-AI-STUDIO.bat
      ماك    : START-AI-STUDIO.command
      لينكس  : start-ai-studio.sh
3. انتظر — سيفتح المتصفح ويشتغل المشروع لوحده
   (أول مرة فقط: يحمّل التشغيل والاعتمادات 2-5 دقائق)

• لا يحتاج تثبيت أي شيء يدوياً — كل شيء تلقائي
• لو ما عندك Node.js سيحمّل نسخة محمولة تلقائياً (ويندوز)

الطريقة 2: التشغيل من GitHub (لو النظام معلّق أو الكمبيوتر غير متاح)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. افتح المستودع:  https://github.com/elazem26/ai-studio
2. اضغط الزر الأخضر  Code  ← تبويب  Codespaces  ←  Create codespace
   أو مباشرة:
   https://github.com/codespaces/new?repo=elazem26/ai-studio
3. انتظر 3-5 دقائق (يُجهّز كل شيء تلقائياً)
4. سيفتح المتصفح على المشروع يعمل مباشرة

• يتطلب حساب GitHub مجاني (Codespaces مجاني 120 ساعة شهرياً)
