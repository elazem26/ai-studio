# AI Studio — نسخة الكمبيوتر الكاملة (v5.6.0)

نسخة مكتبية كاملة تعمل **محلياً على جهازك** دون إنترنت (الذكاء الاصطناعي للمعالجة يعمل بالكامل دون اتصال؛ فقط أدوات توليد الصور النصية تحتاج إنترنت).

---

## ١) المتطلبات (مرة واحدة فقط)

| المتطلب | من أين | ملاحظة |
|---|---|---|
| Node.js نسخة LTS | https://nodejs.org | مطلوب لتشغيل التطبيق |
| Python 3.10 أو أحدث | https://www.python.org/downloads/ | أثناء التثبيت على ويندوز فعّل: **Add python.exe to PATH** |
| حزم بايثون | تُثبَّت تلقائياً عند أول تشغيل | fastapi, onnxruntime, opencv وغيرها (ملف requirements.txt) |

## ٢) التشغيل

### ويندوز
1. فك ضغط الملف كاملاً في مجلد ثابت (مثال: `D:\AI-Studio-Desktop`) — يُفضَّل مساراً قصيراً بلا أحرف عربية.
2. انقر مرتين على **`START-WINDOWS.bat`**.
3. أول تشغيل يستغرق من 10 إلى 20 دقيقة (تثبيت وبناء تلقائي) — التشغيلات التالية تستغرق ثوانٍ.
4. سيفتح المتصفح تلقائياً على `http://localhost:3000`.

### ماك / لينكس
```bash
cd AI-Studio-Desktop
bash START-MAC-LINUX.sh
```
ثم افتح `http://localhost:3000`.

## ٣) ماذا تفعل أداة التشغيل تلقائياً؟

- تنسخ نماذج تبديل الوجوه (856MB) من مجلد `models-insightface` إلى مجلد المستخدم — **مرة واحدة**.
- تثبّت حزم بايثون من `requirements.txt` — **مرة واحدة**.
- تثبّت حزم Node وتُنفّذ `prisma generate` وتُنشئ قاعدة البيانات إن لم توجد — **مرة واحدة**.
- تُبنى نسخة الإنتاج (Next.js standalone) — **مرة واحدة**.
- تشغّل التطبيق على المنفذ **3000** — الخدمات المساعدة (3030 تبديل الوجوه، 3031 إزالة الكائنات) تشتغل تلقائياً عند أول استخدام، ويعاد تشغيلها تلقائياً لو توقفت.

## ٤) الميزات الرئيسية في هذه النسخة

- **إزالة الكائنات بالفرشاة**: حدّد بالفرشاة (4–150 بكسل) أي إضافة — كتابة/شعار/إيموجي/استيكر — أو وشم/تاتو، أو غرض — ساعة/حلق/أسورة — وسيتولى نموذج LaMa المحلي مسحها مع **ترميم ما خلفه** دون المساس ببقية الصورة (البكسلات خارج التحديد تبقى كما هي حرفياً).
- تبديل الوجه والفيديو، تبديل الملابس بمرحلتين، نقل النمط، إزالة الخلفية، تحسين الجودة، الأرشيف المجزأ القابل للتنزيل، ومعرض النتائج الدائم.
- قاعدة البيانات مرفقة (`db/custom.db`) بحسابك وسجلك.

## ٦) حل المشكلات الشائعة

- **ويندوز منع تشغيل الملف (SmartScreen)**: انقر «More info» ثم «Run anyway».
- **بعد فك الضغط لا يعمل التشغيل**: تأكد أن مجلد `models-insightface` و`data` كاملان (الحزمة كبيرة ~1GB).
- **خطأ أثناء تثبيت حزم بايثون**: شغّل يدوياً: `python -m pip install -r requirements.txt`
- **المنفذ 3000 مستخدم**: أغلق أي برنامج يستخدمه، أو عدّل `set PORT=3000` في ملف التشغيل.
- **الجدار الناري سأل عند أول تشغيل**: اسمح بالوصول (التطبيق محلي فقط).
- **البناء فشل**: احذف مجلد `.next` و`node_modules` ثم أعد تشغيل ملف البدء.
